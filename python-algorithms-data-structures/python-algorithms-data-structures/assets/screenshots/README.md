# 📸 Screenshots

This directory documents the screenshots of the algorithms in action.

All screenshots have been captured as real PNG images showing the actual
terminal output of each algorithm. They are stored in the `screenshots/`
subfolder of each algorithm directory.

---

## How to Capture Screenshots

1. Open a terminal in the repository root.
2. Run each Python file as shown below.
3. Capture the terminal output as a screenshot (e.g., using Snipping Tool
   on Windows or `scrot` on Linux).
4. Save the screenshot as a PNG file in the appropriate subfolder.
