# 📸 Screenshots

This directory contains screenshots of the algorithms in action.

Since screenshots are terminal output that should be captured manually,
this file lists which screenshots to capture and how.

---

## How to Capture Screenshots

1. Open a terminal in the repository root.
2. Run each Python file as shown below.
3. Capture the terminal output as a screenshot (e.g., using Snipping Tool
   on Windows or `scrot` on Linux).
4. Save the screenshot as a PNG file in the appropriate subfolder.

## Notes

- Screenshots are **not** auto-generated. They must be captured manually.
- Use a dark terminal theme for better readability.
- Ensure the full output is visible before capturing.
- Recommended image format: **PNG**.
- Recommended width: **800px** (or full terminal width).
