hash-table/
--------------------------------------------------------------------------------
Hash table data structure implementation.

hash-table/hash_table.py
    A complete hash table implementation using separate chaining for
    collision resolution. Includes automatic resizing, dict-like syntax
    (__getitem__, __setitem__, __contains__, __iter__, __len__),
    insert, get, delete, and items methods.

hash-table/README.md
    Documentation for the hash table: purpose, theory, algorithm
    explanation, time/space complexity, example, and how to run.

hash-table/screenshots/
    Placeholder folder for hash table screenshots.

--------------------------------------------------------------------------------
tower-of-hanoi/
--------------------------------------------------------------------------------
Tower of Hanoi recursive puzzle solver.

tower-of-hanoi/tower_of_hanoi.py
    Implements the Tower of Hanoi solution using recursion. Includes
    hanoi_recursive (returns list of moves), hanoi_iterative (iterative
    solution using a stack), and hanoi_count_moves (formula: 2^n - 1).

tower-of-hanoi/README.md
    Documentation for the Tower of Hanoi: purpose, theory, algorithm
    explanation, time/space complexity, example, and how to run.

tower-of-hanoi/screenshots/
    Placeholder folder for Tower of Hanoi screenshots.

--------------------------------------------------------------------------------
graph-algorithms/
--------------------------------------------------------------------------------
Graph traversal and shortest path algorithms.

graph-algorithms/bfs.py
    Breadth-First Search implementation. Includes bfs_traverse
    (level-order traversal), bfs_shortest_path (shortest path in
    unweighted graphs), and bfs_level_order (level-by-level traversal).

graph-algorithms/dfs.py
    Depth-First Search implementation. Includes dfs_traverse_recursive,
    dfs_traverse_iterative, dfs_find_path, and dfs_detect_cycle.

graph-algorithms/dijkstra.py
    Dijkstra's shortest path algorithm. Includes dijkstra (shortest
    distances from source) and dijkstra_shortest_path (path + distance
    between two vertices). Uses a min-heap priority queue.

graph-algorithms/README.md
    Documentation for all graph algorithms: purpose, theory, algorithm
    explanations, time/space complexity, example, and how to run.

--------------------------------------------------------------------------------
recursion/
--------------------------------------------------------------------------------
Recursive algorithm implementations.

recursion/fibonacci.py
    Fibonacci sequence with three approaches: fibonacci_recursive
    (naive, O(2^n)), fibonacci_memoized (with @lru_cache, O(n)), and
    fibonacci_iterative (O(n) time, O(1) space). Also includes
    fibonacci_sequence to generate a list of Fibonacci numbers.

recursion/parentheses_generator.py
    Generates all valid combinations of n pairs of parentheses using
    backtracking. Includes generate_parentheses and count_parentheses
    (Catalan number formula).

recursion/README.md
    Documentation for recursion algorithms: purpose, theory, algorithm
    explanations, time/space complexity, example, and how to run.

--------------------------------------------------------------------------------
sorting/
--------------------------------------------------------------------------------
Sorting algorithm implementations.

sorting/bubble_sort.py
    Bubble sort with early-termination optimization. Includes
    bubble_sort (standard) and bubble_sort_verbose (prints each pass).

sorting/insertion_sort.py
    Insertion sort implementation. Includes insertion_sort (standard)
    and insertion_sort_verbose (prints each step).

sorting/README.md
    Documentation for sorting algorithms: purpose, theory, algorithm
    explanations, time/space complexity, example, and how to run.
